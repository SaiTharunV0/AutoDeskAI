# AutoDeskAI Official IT Service Desk

1. Open this folder in VS Code.
2. Open Terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL shown by Vite.

This is a React + Vite corporate IT-service-desk frontend prototype. The chat and requests use demo/local data until connected to your Python backend. Keep the Gemini API key on the backend, never in React.
